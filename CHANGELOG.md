## [Unreleased]

### Added

- Companion browser slide deck at `presentations/squad-workshop.html`, following Orientation and Modules 1–4.
- Advanced module section for verified v0.11 presets, `squad discover` / `squad delegate`, and honest "sub-squad" patterns using peer squads or git worktrees.

- Context hygiene and economy-mode notes for closing/troubleshooting and budget guidance.

- Set the Squad CLI minimum to 1.1.0 across prerequisites, learner guidance, and the prerequisite verifier.
- Updated the existing module-based workshop in place, retaining its MIT license and upstream attribution.
- Pointed workshop links to `tamirdresher/squad-workshop` and current Squad source/docs to `github/squad` and `github.github.com/squad`; historical issue references retain their original URLs.
- Updated skills references to the current `.github/skills/` location, with fallback notes for older `.copilot/skills/` repos.
- Removed unverified `squad watch` guidance and replaced it with commands/behaviors confirmed in v0.11 public help and docs.
